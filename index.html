Davin Kusuma

Video game creator and visual artist

Award-winning video game creator with experiences as a game designer, animator, artist, and narrative designer. Has created games ranging from jam games to a more experimental approach mostly using Godot, Figma, and Blender as tools. Exhibited interactive installation artworks and has a deep interest in interactive media, notably video games.


Currently working on a project called Spiritwatch.


You can check out the itch.io page for a full list of uploaded projects.
